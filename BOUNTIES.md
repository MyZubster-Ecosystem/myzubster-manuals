# Bounties — MyZubster Manuals

This repository follows the canonical [MyZubster Bounty System](https://github.com/MyZubster-Ecosystem/myzubster/blob/main/BOUNTIES.md).

## Eligible scope

Manual bounties may cover installation guides, deployment/runbooks, recovery procedures, IPFS operations, bounty procedures, robotics guides and security-safe troubleshooting.

## Acceptance

A manual must be executable by another person, state prerequisites, include verification steps and use placeholders rather than real credentials.

## Reward truth

MYZ in the current core platform is an internal reward/accounting ledger. Documentation acceptance/merge is not proof of external settlement.

## Issues

Use this repository's GitHub issues and link the manual PR to the bounty issue.
